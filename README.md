# SecurityEval_Project

This is the AI info security course project. Member: Ruimeng Chen, Shuqi Zhong and Jiayi Li.

Overall Goal:
Our project aims to improve the security evaluation of LLM-generated Python code using selected and updated prompts from SecurityEval. We will first combine existing static analysis tools, custom AST rules, and dynamic security tests to investigate whether this approach identifies vulnerabilities missed by existing static tools alone.
If time permits, we will extend the pipeline to automated code repair. We will compare static-only feedback with combined static and dynamic feedback to evaluate whether the additional feedback helps the LLM fix vulnerabilities while preserving functionality.
